## 12. El número complejo $i^{32}$ es igual a:

### Posibles respuestas:
a) $1$ &emsp;&emsp;&emsp;
b) $i$ &emsp;&emsp;&emsp;
c) $-i$ &emsp;&emsp;&emsp;
d) $-1$ &emsp;&emsp;&emsp;
e) $i^3$ &emsp;&emsp;&emsp;

La clave para resolver este problema es entender las propiedades de los números complejos, especialmente la potencia de la unidad imaginaria $i$.

## Paso 1: Entender las potencias de $i$
- La unidad imaginaria $i$ se define como:
$$\boxed{i = \sqrt{-1}}$$

- Las potencias de $i$ siguen un patrón cíclico:
  - $i^1 = i$
  - $i^2 = -1$
  - $i^3 = -i$
  - $i^4 = 1$
  - Luego, el ciclo se repite: $i^5 = i$, $i^6 = -1$, etc.

## Paso 2: Calcular $i^{32}$
- Para calcular $i^{32}$, podemos usar el hecho de que las potencias de $i$ se repiten cada 4. Entonces, basta con dividir el exponente entre 4 y ver el residuo:

$$32 \div 4 = 8 \quad \text{(residuo 0)}$$

- Como el residuo es 0, entonces tenemos:
 $$\boxed{i^{32} = i^0  = 1}$$
